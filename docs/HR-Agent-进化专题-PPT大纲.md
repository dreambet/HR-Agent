## 进化总览（一句话）

- 上期：三大静态能力（初筛/详细/打招呼）+ 80% 进度，依赖人工触发
- 现在：**7×24 自动监控 + 双向沟通闭环 + 自我进化** 的常驻招聘系统

| 维度 | PPT 中的状态 | 现在的实际状态 |
|---|---|---|
| 交互模式 | 被动响应指令（搜/看/打招呼） | 被动响应 + **主动轮询推送**（工作日每 5 分钟一次） |
| 沟通链路 | 单向：发出招呼语即结束 | **双向闭环**：候选人回复 → 自动推送飞书 → 群内「回复 姓名 内容」直接回传 |
| 简历来源 | 仅搜索库内简历 | 搜索库 + **候选人附件简历自动下载**（仅对新消息触发） |
| 运行方式 | 手动触发 | **5 个常驻 cron**（IM 轮询 / 心跳体检 / 每日总结 / RAG 同步 ×2） |
| 自愈能力 | 无 | Cookie 健康检测 + 401 告警 + **6 小时去重防刷屏**（注：Cookie 恢复依赖招聘官更新，曾持续 13 天失效） |
| 知识沉淀 | RAG 尚在"计划中" | RAG 已落地：**128 篇文档、1073 检索片段、每日 17:30 自动同步** |
| 准确率 | 初筛/详细 85%，打招呼 60%（上期内测口径） | 通过**序号定向 + 多字段同名去重 + 上下文纠偏**修复核心缺陷（新数字未复测，不披露） |
| 交付进度 | 80%，UAT 待启动 | **已实际持续运行中**：累计跟踪会话 542 个，当前活跃约 20 个 |

### 模块二：三大核心能力的深化

**P4 简历初筛 —— 从"能出报告"到"报告可直接用"**
- 载体升级：本地文件 → **飞书在线文档 + 群卡片链接**，自动分享给招聘组群
- 结构化增强：**10 列候选人匹配度排名表**（序号/姓名/性别/年龄/工作年限/学历/教育经历/期望薪资/匹配度/备注）+ 逐人详情 + 招聘建议
- 智能兜底：某地区候选人经验普遍超标时**自动放宽并注明原因**，避免空结果（README 记录的经验自适应）
- 无本地残留：`/tmp` 临时文件用后即清，符合隐私红线
- 支持复合地点：周口-深圳-东莞等多城市一次搜索（包装脚本传入多 city_id）

**P5 详细简历分析 —— 从"信息罗列"到"面试可执行"**
- 报告结构固化为 5 大板块：人物画像 / 岗位匹配度 / **面试建议** / 基本信息 / 履历明细
- 面试建议含：重点考察方向、参考提问、背调关注点、**薪资谈判建议**
- 定位精度：支持 `--index` 序号定向，**同名候选人不再需要二次确认**

**P6 主动打招呼 —— 从"能发出去"到"发对人"**
- 四步链路保持：信息提取 → 岗位匹配 → 意图识别 → 话术生成
- **关键修复**：报告展示顺序 ≠ API 原始序号，曾导致错投；现统一以 API 上下文序号定位
- **同名去重增强**：页面多人重名时，按年龄 + 工作年限 + 学历多字段加权命中
- 职位自动匹配 + AI 招呼语生成，结果卡片回传飞书群

### 模块三：四项全新能力（本期最大增量）

**P7 【新增 1】IM 双向沟通闭环 ⭐ 核心突破**
- 打通智联 IM 全套接口：会话列表 / 会话详情 / 发送文本 / 未读统计（im_monitor.py）
- 候选人一回复，**工作日每 5 分钟轮询**自动推送飞书群卡片（含姓名、岗位、原文、时间）
- 招聘官群内输入 **「回复 张三 您好，方便电话沟通吗」** → im_reply.py 直达候选人
- 系统消息自动过滤，只推真人消息，不打扰

**P8 【新增 2】附件简历自动下载**
- 候选人发来的附件简历自动识别并落地
- 仅对**新消息**触发下载，避免重复抓取与超时

**P9 【新增 3】自动值班体系（cron 实测 5 个任务）**
| 任务 | 频率 | 作用 |
|---|---|---|
| 智联IM消息轮询 | 工作日 8-12、13-17 点每 5 分钟 | 候选人消息零遗漏（cron 实际配置） |
| 智联简历12小时心跳检测 | 每日 04:00 | Cookie 有效性 + 接口可用性 + 简历库水位 |
| 每日工作总结同步 | 周一至周六 17:30 | 当日候选人动态汇总推送 |
| RAG知识库每日同步 | 周一至周六 17:30 | 经验自动入库 |
| daily-summary-rag | 周一至周五 17:30 | 每日总结 + RAG 联动 |

- **异常告警**：Cookie 失效自动识别 401，向群内告警，并按 6 小时去重避免刷屏
- **诚实说明**：Cookie 失效后**必须由招聘官更新 Cookie 才能恢复**，系统本身无法自愈（08-14~08-26 曾连续失效 13 天）

**P10 【新增 4】RAG 本地知识库 —— 自我进化落地**
- 上期是"改进计划"，现已**建成投产**
- 规模：128 篇知识文档 / 1073 检索片段（源自 MEMORY 记录的索引重建结果）/ 本地 BM25 检索
- 技术：BM25 + Jieba 中文分词，本地检索、零外传
- 机制闭环：**使用 → 总结 → 检索 → 复用**，故障可快速定位历史解法
- 配套 `.learnings` 体系：错误记录（ERRORS）、经验教训（LEARNINGS）、功能需求（FEATURE_REQUESTS）三类分档沉淀
